 ReadyQuest – Milestone 2 Development Report
 
## FEATURES ADDED

During Week 2, I expanded ReadyQuest by adding and improving several features:

- Emergency preparedness lessons that explain what to do before, during, and after an emergency.
- Interactive emergency scenarios that allow users to make decisions and receive feedback.
- Scoring that awards points for correct decisions and subtracts points for unsafe decisions.
- A household preparedness checklist that tracks responses and calculates a preparedness score.
- Progress tracking for completed lessons, completed scenarios, and total points.
- Achievements that reward users for completing lessons and making safe decisions.
- Random emergency events, including tornadoes and water supply interruptions.

 ## Updates to Code Structure

I continued organizing ReadyQuest using separate classes, with each class responsible for a specific part of the application.

I improved how the Lesson, Scenario, Household, and ProgressTracker classes work with the main program.

The ProgressTracker records completed lessons and scenarios, updates points, and checks achievements. The Household class tracks checklist responses and calculates the household preparedness score.


 ## Usability Improvements

I improved input validation so users receive feedback when they enter invalid menu choices or answers.

I also improved program feedback by displaying points earned or lost, completed activities, and achievements.

These improvements help users understand their choices, navigate the program, and see how their decisions affect their progress.



 ## What Changed and Why

ReadyQuest developed from its initial program structure into a more interactive household emergency preparedness application.

I added features that allow users to learn about emergencies, practice making safety decisions, review household preparedness, and monitor their progress.

I made these changes to make the application more useful and engaging while improving how its classes work together.

## Next Steps

My next priorities are to continue testing the existing features, improve household preparedness feedback, add a welcome introduction and ASCII art, and prepare the Save and Load functionality planned for Week 4.
